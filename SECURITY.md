# Security Policy

Aircoda takes security seriously. We appreciate your efforts to responsibly disclose security issues.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | Yes                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Aircoda, please do NOT create a public GitHub issue.

Instead, please report security vulnerabilities directly to the maintainers at `security@aircoda.org` or open a private security advisory on GitHub.

Please include:
- A description of the vulnerability and impact.
- Steps or proof-of-concept to reproduce the issue.
- Affected operating system(s) and Aircoda version.

We will acknowledge receipt of your vulnerability report within 48 hours and provide regular status updates on remediation.
