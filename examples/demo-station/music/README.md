# Audio Tracks Directory

Place your audio files here.

Supported audio formats:
- MP3 (`.mp3`)
- WAV (`.wav`)
- OGG (`.ogg`)
- FLAC (`.flac`)
- M4A (`.m4a`)
- AAC (`.aac`)

> [!NOTE]
> Please ensure you have appropriate rights, licenses (e.g. Creative Commons, Public Domain), or permission to broadcast any audio files included in public stations.
